# G 牌路考观察要求（只用于 G 牌标准，G2 不变）

来源：用户整理（2026-11-27），对照 G 评分表（lib/sheet.js 的 `G`）。

按钮约定（G 牌）：
- “中、侧镜”：看中镜＋该侧侧镜（扣分项：后视镜）
- “盲点”：转头看该侧盲点（扣分项：盲点，单独扣）
- 完成转弯后，“中、侧镜”改为“中镜”，只看中镜

## 一、转弯（左 / 右）
1. 接近路口：中镜、侧镜 → TU.a1.A；盲点 → TU.a2.A（两个独立扣分项）
2. 如果停车：等待时观察路口、镜子、盲点 → TU.s3.A
3. 转弯时：路口左右左 → TU.t1.A；盲点 → TU.t2.A
4. 完成转弯后：加速到车流速度前看中镜 → TU.c2.A（Complete turn · Traffic check: Not by traffic speed）

## 二、换线（市区 / 高速）
- “中、侧镜” LC.1.B 和 “盲点” LC.2.A 是分开的扣分项

## 三、高速
1. 上高速：左换线，要求同市区左换线（镜子、盲点分开扣）EX.e1.B / EX.e2.A
2. 高速上行驶：每 5 秒看一次中镜（加“中镜”按钮，适当加长高速行驶距离）EX.d1.A
3. 出高速：右换线，要求同市区右换线（镜子、盲点分开扣）EX.x1.B / EX.x1.C

## 四、停在路口（直行遇红灯停车等灯）
1. 接近：看后视镜
2. 停下：看后视镜
3. 起步：路口左右左；过路口后看后视镜

停牌路口起步后加速到车流速度前看中镜 → SI.r3.A（Stop intersection · Starting · Traffic check: Not by traffic speed）

## 五、通过路口（绿灯直行）
1. 接近：左右左观察、后视镜观察 TI.h1.A / BR.4.A
2. 通过：过路口后看中镜 TI.u2.A
